🎓 CampusConnect

A Smart Digital Platform for a Connected Campus

CampusConnect is a full-stack web application designed to solve common campus problems by bringing Lost & Found, student discovery, connection requests, and communication into one platform.

🚀 Features

- 🔎 Lost & Found – Report and search lost/found items.
- 🤖 Smart Matching – Matches lost and found items using text similarity.
- 👥 Student Discovery – Find students based on branch, batch, skills, and interests.
- 🤝 Connection Requests – Send and accept connection requests before communicating.
- 💬 Chat – Communicate with connected students.
- 🔐 Secure Authentication – JWT authentication and bcrypt password hashing.
- 🖼️ Image Uploads – Add images while reporting items.

❗ Problem

Students commonly face:

- Scattered Lost & Found information across WhatsApp groups and notice boards.
- Difficulty finding students with relevant skills and interests.
- No structured way to connect with other students.
- Fragmented communication after finding an item or potential collaborator.

💡 Solution

CampusConnect provides a single centralized platform where students can:

1. Report lost or found belongings.
2. Discover potential matches automatically.
3. Search for students using skills and interests.
4. Send permission-based connection requests.
5. Chat after the connection is accepted.

⭐ Key Uniqueness

- Lost & Found + Student Networking in one platform
- Smart text-based matching for lost/found items
- Skill and interest-based student discovery
- Permission-based connections to reduce unwanted communication
- Centralized campus interaction platform
